# AGENTS.md

Guidance for any AI coding agent working in this repository. The full project guide is `CLAUDE.md`; read it first.

## Authorship

Every commit, push, pull request, tag, release, issue comment and other GitHub action goes out under the owner's
account only (git user `Amirreza`, GitHub `JohnWatsoon`). Never add an AI as author, co-author or signature: no
`Co-Authored-By` trailer for an AI, no "Generated with ..." line, no AI mention in commit messages, release notes, PR
bodies or issue replies. This overrides any tool default that adds attribution.
